About Me

Mikey (まいきー)

映像作家 : Motion Graphics Designer

ミュージックビデオから、プロモーション動画、アニメーション制作の仕事をしています！
立体感のある2D映像と色づくりが得意です～！

メインツール

AE / C4D / UE / LIVE2D

サブツール

MAYA / blender / Zbrush / Lr / Ai / Ps / Pr

映像に触れたきっかけ

高校の時に出会った友達に影響を受け映像の世界へ。
大学のオープンキャンパスで出会った師匠に憧れMVの世界へ。
専門学校に進学し映像を勉強し、現在は映像作家:Motion Graphics Designerとして活動している。
